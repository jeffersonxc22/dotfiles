# Temas do kitty

Arquivos `mocha.conf`, `macchiato.conf`, `frappe.conf` e `latte.conf` copiados
do repositório [catppuccin/kitty](https://github.com/catppuccin/kitty)
(`themes/`), licença MIT.

Eles definem a paleta ANSI dos 16 cores. `theme/kitty-colors.sh` inclui o
arquivo do flavour atual e sobrescreve fundo, texto, cursor e seleção com os
valores do `kdeglobals`.
